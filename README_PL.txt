NOVA CUT 10.1 — AUTO SUBTITLES PRO

Zachowano funkcje NOVA CUT 10.0, import MP4, ikonę NOVA SIGNATURE i dotychczasowy renderer Windows.

Nowości:
- w panelu AI Studio przycisk Generuj napisy z MP4
- wybrany film lub wszystkie filmy na osi czasu
- wybór języka (auto/PL/EN/DE/ES) i modeli Whisper Base/Tiny
- poprawione mapowanie czasów przy przycinaniu i zmianie prędkości
- edytowalne napisy na osi czasu, zapis projektu, eksport SRT
- natywny MP4 dodaje przełączalny strumień napisów mov_text oraz oddzielny plik SRT. Napisy NIE są na stałe wypalane w obrazie. Włącz je w odtwarzaczu.
- rozpoznawanie offline, bez wysyłania nagrań do chmury

Uwaga: Whisper wymaga zbudowania Windows EXE z dodatkowymi zasobami (GitHub Actions), a podgląd HTML nie transkrybuje.

Testy: npm run check.
