◈ ULTRA CINEMA · BIG SCREEN

Tryb kinowy inspirowany projekcją wielkoformatową. Nie jest certyfikowany przez IMAX.

Wybierz format 1.43:1 lub 1.90:1.

Render 4K–10K zalecany przez Windows FFmpeg. Audio jest stereo, nie Dolby Atmos / 5.1. Zakres rozdzielczości zależy od formatu kadru.

Warstwa V2 nakłada się na V1. Możesz przesuwać klipy i dodawać ciszę lub nakładki. Tryb automatyczny dobiera silnik eksportu. Dla 4K–8K na Windows naciśnij „Zapisz cały folder eksportu Windows” w Chrome/Edge, następnie uruchom dołączony renderer FFmpeg. Napisy animowane i naklejki w rendererze Windows nie są jeszcze uwzględniane.

Kodek i sprzętowe przyspieszanie zależą od przeglądarki.
🔊 Audio: sprawdzenie przed eksportem.
Ustaw silnik Automatyczny, aby program dopasował eksport do projektu.
10K jest profilem eksperymentalnym Windows: 9600×5400 (16:9), a w trybie ULTRA CINEMA wymiary zależą od proporcji; HEVC/AV1 (jeśli dostępne), rekomendowane ≥16 GiB wolnej pamięci, dużo miejsca na dysku. Brak gwarancji odtwarzania na urządzeniach. Nie zmieniamy rozdzielczości bez Twojej decyzji.
Tryb AUTOMATYCZNY wybiera FFmpeg.wasm (MP4 + AAC) dla krótkich, prostych projektów do 1080p, a MediaRecorder dla większych projektów i efektów Canvas. W razie błędu próbuje drugiego silnika, jeżeli jest dostępny. Dla wyższej niezawodności 4K–8K na PC użyj „Zapisz cały folder eksportu Windows” — Chrome/Edge skopiuje oryginalne pliki wraz z rendererem. Skrypty wymagają Python 3 i FFmpeg. FFmpeg.wasm pobiera ~32 MB przy pierwszym uruchomieniu. Żaden silnik nie może zagwarantować 8K na dowolnym urządzeniu.
Windows · eksport lokalny FFmpeg z MP4/AAC. Uwaga: animowane napisy, naklejki i efekty ruchu wciąż wymagają eksportu przeglądarkowego.

4K/6K/8K w przeglądarce mogą być automatycznie obniżane. Dla dokładnego wyjścia 4K/6K/8K na Windows zalecany jest renderer FFmpeg. Przeglądarki mobilne i starsze karty graficzne mogą nie obsługiwać tak dużego eksportu. Rozdzielczość wyjściowa nie zwiększa szczegółowości materiałów źródłowych. Przy nagrywaniu przez MediaRecorder silnik przeglądarki sam decyduje, czy użyje sprzętowego enkodera. Przycisk „Sprawdź kodowanie” bada dostępność interfejsów i preferencji, ale nie gwarantuje sprzętowego eksportu. H.265 bywa niedostępny, a ustawiony bitrate jest tylko wartością żądaną.
